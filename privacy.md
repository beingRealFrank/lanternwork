# Privacy policy

*Last updated: 13 November 2026*

Lanternwork plugins run entirely inside your IDE.

- They do not collect, store or transmit any personal data, usage data or telemetry.
- They make no network connections of their own. Some features run tools you have installed locally (for example a command-line tool you point them at); those tools are governed by their own terms.
- If a plugin later offers a paid tier, licence checks are done by the JetBrains platform and JetBrains Marketplace, under JetBrains' own privacy policy. Lanternwork receives only what JetBrains provides to vendors for sales and invoicing.
- If you open an issue on GitHub, what you write there is public and governed by GitHub's privacy statement.

Questions about this policy: open an issue in the relevant plugin's issue tracker, linked from the [home page](./).
