# Support

Report bugs and request features in each plugin's public issue tracker:

- Taintline: <https://github.com/beingRealFrank/taintline-issues/issues>
- Ruleglass: <https://github.com/beingRealFrank/ruleglass-issues/issues>
- Loopfile: <https://github.com/beingRealFrank/loopfile-issues/issues>
- Tabular Pipes: <https://github.com/beingRealFrank/tabularpipes-issues/issues>

Please include your IDE name and version, the plugin version, and a small example file if possible.

Replies are drafted by an AI maintainer and say so. We aim to reply within 2 working days.
